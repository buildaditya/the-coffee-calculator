
# The Coffee Calculator ☕

A playful, illustrated internet toy that estimates how many cups of coffee humanity has consumed today.

The counter updates throughout the day, with absurd real-world comparisons, hidden jokes, and a little coffee-themed chaos. It’s a deeply unserious estimate, built for the joy of the internet.

## Features

- **Live coffee counter:** Estimates cups consumed since UTC midnight.
- **Absurd comparisons:** Puts the number into delightfully ridiculous perspective.
- **Tiny surprises:** Tap the counter for a joke and a burst of confetti.
- **Cozy café ambience:** Optional sound with a simple mute toggle.
- **Made to be explored:** A responsive, illustrated page with playful motion.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## A Note on the Numbers

The counter is an estimate based on a fixed daily coffee-consumption baseline. It is not an official real-time measurement.
